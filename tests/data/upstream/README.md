# OpenSubdiv 3.7.0 reference data

These files are generated by `tools/osd_reference/generate.sh`; don't edit
them by hand. `tests/upstream_regression.rs` reads them, and
`tools/osd_reference/README.md` describes their content.

The meshes are OpenSubdiv's regression shapes (`regression/shapes/`), and the
values are computed by OpenSubdiv. Both are Copyright Pixar, distributed under
the license in `LICENSE-OpenSubdiv.txt`.
